# Pickup Lines for Machines

Entry for the [make.fun](https://make.fun/r/41fw6r6c) **Pickup Lines for Machines** (`u-gentle-badger-68-pickup-lines-for-machines-131631a1`) bounty.

## Usage

Runs on Node 22+ (`program/v1`) with zero external dependencies and writes the deterministic single-line UTF-8 entry (1–200 characters) to `/output/entry.txt`:

```bash
node main.ts
```

For local verification into a custom output path:

```bash
node main.ts --out /tmp/entry.txt
```
